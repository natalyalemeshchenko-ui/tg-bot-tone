# Бот тональности комментариев

Telegram-бот для одного публичного канала. Он администратор канала и привязанного чата обсуждения. Сохраняет посты и комментарии, которые появились после его запуска, и по ссылке на пост отвечает диаграммой тональности и коротким резюме.

Тональность в боте считает локальная модель `blanchefort/rubert-base-cased-sentiment`. Резюме пишет GigaChat по тексту комментариев: что хвалят, что ругают и о чём говорят.

## Hugging Face MCP

Перед ботом тональность проверялась через MCP-сервер Hugging Face. Сервер подключён к аккаунту Hugging Face и даёт доступ к Hub и к Spaces.

Что делали:

1. Через `hf_fs` нашли публичные MCP Spaces для анализа тональности.
2. Через `dynamic_space` посмотрели параметры и вызвали классификатор. Английская модель [hugging-apps/sentimental-0-2m-demo](https://huggingface.co/spaces/hugging-apps/sentimental-0-2m-demo) для русских отзывов не подошла: она обучена на IMDB, SST и твитах.
3. Четыре отзыва из `test.md` прогнали через [Hariharasudhan07/qwen3-0.6b-sentiment-classification](https://huggingface.co/spaces/Hariharasudhan07/qwen3-0.6b-sentiment-classification). Это Qwen3-0.6B с головой на три класса: positive, neutral, negative.

Результат по `test.md`: 3 позитивных отзыва с уверенностью около 99,7% и 1 негативный с уверенностью 86,1%. Нейтральных не было. У негативного отзыва оставалось около 12% positive: в тексте есть и попытка сервиса помочь.

Такой вызов бесплатный в пределах дневной квоты ZeroGPU. У бесплатного аккаунта это 5 минут GPU в сутки, у PRO — 40 минут. Деньги списываются только если платный аккаунт уже выбрал квоту и включены предоплаченные кредиты: $1 за 10 минут сверх лимита.

В боте MCP на каждый комментарий не вызывается. Очередь Space и дневные 5 минут не подходят для потока сообщений, а маленькая английская модель плохо читает русские отзывы. Поэтому в рантайме стоит русская модель `blanchefort/rubert-base-cased-sentiment`, скачанная с Hugging Face. Она работает локально и квоту ZeroGPU не тратит.

Старые посты и комментарии бот не выгружает. Непрочитанные обновления Telegram хранит около суток, поэтому бота лучше не выключать надолго.

## Запуск

Нужен Python 3.12.

```bash
pip install -r requirements.txt
```

Скопируйте `EnvExample` в `.env` и заполните:

- `TELEGRAM_BOT_TONE_TOKEN` — токен от @BotFather
- `GIGACHAT_AUTH_KEY` — ключ авторизации GigaChat, с префиксом `Basic` или без него

Бот должен быть администратором канала и чата обсуждения. Дополнительные права не нужны: достаточно статуса администратора, чтобы он видел посты и все сообщения чата.

```bash
python bot.py
```

При первом разборе комментариев модель скачается с Hugging Face.

В личный чат бота любой пользователь может прислать ссылку на пост, например `https://t.me/channel/123`. В ответ придёт диаграмма и резюме. Если комментариев ещё нет, бот так и напишет.

## Сертификаты для GigaChat

Файлы сертификатов в репозиторий не входят. Без них диаграмма строится, а резюме GigaChat не запрашивается: сервер Сбера не проходит обычную проверку сертификата.

Скачайте сертификаты Russian Trusted CA со страницы [Госуслуг](https://www.gosuslugi.ru/crt) и положите файлы `.cer` в папку `Russian_Trusted_CA` рядом с `bot.py`.
